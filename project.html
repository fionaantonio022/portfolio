ALERTO

IoT Hardware and Mobile Application Ecosystem

Development of a Smart Location-Based Alert System and Hardware Anti-Theft Device for Commuter Safety

A comprehensive, multi-platform safety ecosystem designed to protect public transit commuters. The system features an AI-powered mobile app built with React Native that provides live tracking, dynamic geofencing, route deviation alerts, and a Google Gemini AI integration for Automated Grab Assist (OCR) to extract driver details from ride-hailing screenshots.

The app pairs with an independent IoT smart bag module powered by an ESP32-S3 microcontroller. The physical hardware utilizes Untethered Dead Reckoning (UDR) for continuous tracking in dead zones, strong haptic wake-up alarms requiring physical interaction, intrusion detection sensors (magnetic reed, LDR), and an embedded Air780E 4G GSM module for offline cellular fallback and emergency SMS dispatch.
