IoT Hardware and Mobile Application

ALERTO: Development of a Smart Location-Based Alert System and Hardware Anti-Theft Device for Commuter Safety

A comprehensive, multi-platform safety ecosystem designed to protect public transit commuters. The system features an AI-powered mobile app built with React Native that provides live tracking, dynamic geofencing, route deviation alerts, and a Google Gemini AI integration for Automated Grab Assist (OCR) to extract driver details from ride-hailing screenshots.

The app pairs with an independent IoT smart bag module powered by an ESP32-S3 microcontroller. The physical hardware utilizes Untethered Dead Reckoning (UDR) for continuous tracking in dead zones, strong haptic wake-up alarms requiring physical interaction, intrusion detection sensors (magnetic reed, LDR), and an embedded Air780E 4G GSM module for offline cellular fallback and emergency SMS dispatch.

Ligtas Sundo

Web Application and RFID Verification System

Ligtas Sundo: QR Code and RFID with SMS Notifications and Cloud Storage for Noveca Day Care Student Dismissal

A unified, technology driven dismissal system designed to guarantee the safe and secure pick-up of students. The platform replaces traditional, manual fetcher IDs which are susceptible to fabrication and human error with a robust digital verification system that associates students with up to three authorized fetchers. It features a responsive dashboard built with Flutter that allows school administrators and teachers to actively oversee dismissals, generate printable ID reports, and track weekly pick-up trends using built-in data analytics.

The software pairs with an RFID reader (13.56 MHz) for automatic student attendance logging and utilizes webcam integration to scan unique QR codes to securely validate authorized fetchers. Upon a successful scan, the system leverages the IPROG SMS Gateway to send instant, automated text notifications to parents, ensuring real-time communication and preventing unauthorized pick-ups.
